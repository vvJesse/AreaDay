ResearchRamp 初次设置

获取你的 OpenAlex API Key

免费 Key 可以提高跨学科论文检索和公开全文获取的可用额度。完成后请回到设置窗口，在隐藏输入框中粘贴 Key；ResearchRamp 会自动验证并安全保存。

1

打开 OpenAlex API 设置

登录或免费创建 OpenAlex 账户，然后进入 API 设置页面。

打开 OpenAlex Settings ↗
2

复制完整的 API Key

在设置页面复制完整 Key，不要复制变量名、引号或其他说明文字。

3

回到设置窗口并粘贴

回到 AreaDay 打开的设置窗口，将 Key 粘贴到隐藏输入框并按回车。ResearchRamp 会自动验证并保存；看到确认成功后，你就可以离开。不需要打开或编辑 credentials.ini。

本页面不会读取、接收或保存你的 Key。Key 只写入这台电脑上的 ResearchRamp 配置文件。
